
Este projeto consiste em uma aplicação web desenvolvida em Python utilizando o framework Flask, com foco na implementação de um sistema completo de gerenciamento de biblioteca. A aplicação permite o cadastro estruturado de livros com informações como título, autor, número de páginas e quantidade disponível, além do registro detalhado de usuários contendo nome, sobrenome, CPF e telefone.

O sistema realiza o controle integral do fluxo de empréstimos e devoluções, associando cada movimentação a um usuário específico e registrando automaticamente data e horário das operações. O histórico é preservado mesmo após a devolução, permitindo o acompanhamento completo das movimentações e o controle preciso do estoque de livros disponíveis.

A arquitetura do projeto foi organizada seguindo princípios de Programação Orientada a Objetos e separação de responsabilidades, dividindo a aplicação em camadas distintas de modelos, regras de negócio e rotas da aplicação. A persistência dos dados é realizada por meio de arquivos JSON, garantindo armazenamento estruturado e leitura eficiente das informações.

Este projeto demonstra aplicação prática de conceitos fundamentais de desenvolvimento backend, como implementação de CRUD completo, manipulação de dados estruturados, controle de estado de objetos, organização modular de código e integração entre backend e interface web.

O sistema pode ser executado localmente com Flask e foi desenvolvido com o objetivo de consolidar conhecimentos em desenvolvimento web, estruturação de aplicações e construção de projetos sólidos para portfólio profissional.
